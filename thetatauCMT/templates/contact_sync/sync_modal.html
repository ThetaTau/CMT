Apple does not offer a public OAuth API for iCloud Contacts, so we cannot push contacts directly to iCloud. Download the vCard file below and import it:

  1. Click Download vCard.
  2. On macOS: double-click the .vcf file and Contacts.app will prompt you to add all cards.
    On iOS: open the .vcf attachment from Mail or Files, tap Share → Contacts → Add All Contacts.
  3. Anything you add on any Apple device automatically syncs to your other iCloud devices.
